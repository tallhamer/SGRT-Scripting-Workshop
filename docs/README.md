# Workshop materials, one folder per product

The notebooks are the workshop. These are the materials around them: what to hand attendees, how
to run a session, and how to extend each product's data.

| Folder | Workshop | Contents |
| --- | --- | --- |
| [`MapRT/`](MapRT/) | MapRT Scripting Workshop | [Handout](MapRT/handout.md) (give this to attendees) · [Run-sheet](MapRT/run-sheet.md) (timings, what to demo, where people get stuck) · [Slide outline](MapRT/slides-outline.md) · [Adding data](MapRT/adding-data.md) (rooms, patients, surfaces, maps, plans) |

AlignRT, SimRT and DoseRT get a folder here when their workshops are written. Each should have at
least a handout and a run-sheet. See the "Adding a product" checklist in
[`data/README.md`](../data/README.md).
